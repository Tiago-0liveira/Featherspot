## Playback implementations

On Windows, lspotify can use Spotify's documented Web Playback SDK or the unofficial Librespot
implementation. On macOS and Linux, local playback currently uses Librespot. Remote Spotify
Connect control uses Spotify's documented Web API.

[Librespot](https://github.com/librespot-org/librespot) is an independent, reverse-engineered
open-source Spotify client implementation. It is not an official Spotify SDK and Spotify does not
support or endorse it. Spotify may change its private protocols or policies at any time, which can
make Librespot playback stop working.

Users who do not want to use Librespot can use the official Web Playback SDK option on Windows or
use lspotify only as a controller for another Spotify Connect device.
